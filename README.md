# Magpie Enterprise

This fork of [Magpie](https://github.com/yetone/magpie) has two deliverables:

- A Docker gateway for managing company model API credentials, routing groups, employee keys and usage.
- A desktop app that connects Claude Code and Codex to the company gateway through Remote Magpie.

See the [build, deployment and verification guide](docs/subsystems/enterprise-editions.md).
